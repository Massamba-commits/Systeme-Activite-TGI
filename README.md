# Application Web d'Authentification

Application web moderne avec système d'authentification sécurisé.

## 🚀 Technologies

### Backend
- Python 3.11+
- Flask
- PostgreSQL/Mysql
- JWT Authentication

### Frontend
- React 18
- Tailwind CSS
- Vite

## 📋 Prérequis

- Node.js 18+
- Python 3.11+
- PostgreSQL 15+
- Git

## 🛠️ Installation

### Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
